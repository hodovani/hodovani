## Selected projects

These are independent projects exploring interface design, frontend architecture, and AI integration.

### Workbench — React & TypeScript AI chat
A work-in-progress chat application built with Next.js and React. The current implementation includes streamed Gemini responses, loading/error states, and retry behavior, with separate components for UI, conversation state, and model integration. The live prototype requires a user-provided Gemini API key.

[Demo — API key required](https://hodovani.github.io/workbench/) · [Code & setup](https://github.com/hodovani/workbench)

### Model Explorer — API-backed interface
An interface built with native Web Components, with separate modules for API access, application state, templates, and focus management. The case study explains the design decisions and support for browser agents.

[Demo](https://hodovani.github.io/projects/model-explorer/) · [Code](https://github.com/hodovani/hodovani.github.io/tree/master/projects/model-explorer) · [Case study](https://hodovani.github.io/2026/08/27/designing-an-api-backed-model-explorer.html)

### AI Guardrail Policy Builder — multi-step form
A frameworkless form built with HTML, CSS, JavaScript, and Web Components, exploring validation, browser storage, keyboard interaction, and accessible form behavior.

[Demo](https://hodovani.github.io/projects/multi-step-form/) · [Code](https://github.com/hodovani/hodovani.github.io/tree/master/projects/multi-step-form) · [Case study](https://hodovani.github.io/2026/08/25/building-a-frameworkless-multi-step-form.html)
